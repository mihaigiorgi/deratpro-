# Design prompt — Google Stitch

Promptul folosit ca punct de plecare pentru conceptul vizual:

```text
Create a premium modern landing page for a Romanian pest control company called "DeratPro".

The company provides professional:
- rodent control
- pest control
- disinfection services

The website should target both residential and commercial customers.
Design a high-converting, trustworthy, modern landing page.

Visual direction:
- premium
- minimalist
- professional
- clean
- trustworthy
- modern technology-inspired aesthetic
- dark navy / charcoal background
- off-white surfaces
- vibrant green/lime accent
- subtle gradients
- refined glassmorphism
- rounded cards
- elegant typography
- generous whitespace

The landing page should contain:
1. Hero section
   - DeratPro logo
   - strong headline
   - supporting text
   - primary CTA "Solicită o ofertă"
   - secondary CTA
   - abstract 3D/particle visual suggesting protection, precision and pest control technology
2. Services section
   - Deratizare
   - Dezinsecție
   - Dezinfecție
   - three premium service cards with icons
3. Why DeratPro section
   - fast response
   - approved products
   - authorized professionals
   - service guarantee
4. Process section
   - Contact
   - Evaluation
   - Intervention
   - visually represented as a 3-step process/timeline
5. Contact section
   - name
   - phone
   - message
   - strong CTA
   - clean conversion-focused layout
6. Footer

Use subtle animations and micro-interactions.
The design must be fully responsive for desktop, tablet and mobile.
Avoid generic stock-template aesthetics.
Make the website feel like a premium Romanian service company with a modern technology-oriented identity.
Do not invent real certifications, statistics, awards or customer testimonials.
```
